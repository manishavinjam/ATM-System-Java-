# 🏧 ATM System — Java

A Mini ATM System built using Java OOP concepts as part of TechnoHacks Internship.

## 💡 Features
- Account login with PIN authentication
- Check balance
- Deposit money
- Withdraw money
- 3 attempt PIN validation
- Multiple account support

## 🛠️ Technologies Used
- Java
- OOP concepts — Classes, Objects, Methods
- Exception Handling
- Scanner for user input

## 📂 Files
- `Account.java` — Account class with all banking operations
- `ATMSystem.java` — Main ATM system with menu and login
